# Multi-Modal AI Search Agent

An AI-powered search system supporting text and image queries using embeddings, vector search, and LLM-based reasoning.

## Features (Planned)
- Semantic search (text)
- Image search (CLIP)
- Multi-modal queries
- LLM agent reasoning
- Hybrid retrieval

## Tech Stack
- FastAPI
- FAISS
- SentenceTransformers
- CLIP (planned)
